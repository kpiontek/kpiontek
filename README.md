### What I'm building

**[SiteCMD](https://sitecmd.com)** is a desktop app, CLI, and MCP server that scan live
sites and source code with 420+ deterministic checks, then hand the exact fixes to
whatever editor you already use. Rust, Tauri, React, TypeScript, Cloudflare.

**[Visit Your Team](https://visityourteam.com)** is a game-day guide to all 124 NFL, NBA,
NHL, and MLB venues, with real prices, insider tips, and a trip cost calculator.
Next.js on Cloudflare.

**[Was It Vibed](https://wasitvibed.com)** scores any public website against 46 signals
for AI-generated patterns, with no model in the scoring loop. Cloudflare Workers, D1,
Durable Objects.

**[SmartHomeU](https://smarthomeu.com)** teaches smart home setup through 22 free courses
and tracks live retail pricing across about a thousand products. Drupal 11 with a
Node.js scraping service.
